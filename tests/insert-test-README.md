# מדריך טסט למסך הכנסת נתונים

## תיאור כללי
מסך הכנסת נתונים מאפשר רישום נוכחות תלמידים עבור אירועים שונים. המסך כולל שתי זרימות עיקריות:
1. **יצירת אירוע חדש** - בחירת תאריך ואירוע והתחלת רישום
2. **עריכת אירוע קיים** - בחירה מרשימת אירועים קיימים

## מפת זרימת המשתמש (User Flow)

### 🎯 זרימה ראשית - יצירת אירוע חדש

```
מסך בחירת אירוע ← בחירת תאריך עברי ← בחירת אירוע ← התחל רישום ← מסך רשימת תלמידים ← רישום נוכחות ← עידכון ← הצלחה
```

**שלבים מפורטים:**
1. **טעינת הדף** - המתנה לכותרת "רישום אירוע"
2. **בחירת תאריך עברי** - לחיצה על שדה "תאריך עברי" ובחירה מהלוח
3. **בחירת אירוע** - פתיחת רשימה "אירוע" ובחירת אירוע
4. **התחלת רישום** - לחיצה על כפתור "התחל רישום"
5. **מסך רשימת תלמידים** - המתנה לרשימה (או הודעה "לא נמצאו תלמידים")
6. **רישום נוכחות** - לחיצה על תלמידים לסימון נוכח/חסר
7. **עידכון נתונים** - לחיצה על כפתור העידכון
8. **אישור הצלחה** - בדיקת הודעה "העדכון הצליח!"

### 📋 זרימה משנית - עריכת אירוע קיים

```
מסך בחירת אירוע ← בחר אירוע קיים ← רשימת אירועים ← בחירת אירוע ← התחל רישום ← עריכת נוכחות
```

**שלבים מפורטים:**
1. **בחירת אירוע קיים** - לחיצה על "בחר אירוע קיים"
2. **מסך טעינה** - המתנה להודעה "טוען אירועים..."
3. **רשימת אירועים** - המתנה לרשימה (או "אין אירועים קודמים")
4. **בחירת אירוע** - לחיצה על אירוע מהרשימה
5. **התחלת רישום** - לחיצה על "התחל רישום"
6. **עריכת נוכחות** - שינוי נוכחות קיימת

## טקסטים עבריים מדויקים

### 🏷️ תוויות וכותרות
- **"רישום אירוע"** - כותרת הכרטיס הראשי
- **"בחר אירוע לרישום"** - תת-כותרת
- **"תאריך עברי"** - תווית שדה התאריך
- **"אירוע"** - תווית רשימת האירועים

### 🔘 כפתורים
- **"התחל רישום"** - כפתור התחלת רישום (כחול, LoadingButton)
- **"בחר אירוע קיים"** - כפתור בחירת אירוע קיים (outlined)
- **"חזור"** - כפתור חזרה (עם חץ)
- **"העתק"** - כפתור העתקת נתונים
- **"הדבק"** - כפתור הדבקת נתונים
- **"מחק"** - כפתור מחיקת אירוע

### 📊 תוויות סיכום
- **"נוכחים"** - מספר הנוכחים (צבע ירוק)
- **"חסרים"** - מספר החסרים (צבע אדום)
- **"מתוך"** - סה"כ תלמידים (צבע ברירת מחדל)

### 🔍 פילטרים וחיפוש
- **"סדר לפי"** - תפריט סידור
  - **"סדר עולה"** - מיון עולה
  - **"סדר יורד"** - מיון יורד
  - **"שם פרטי"** - מיון לפי שם
- **"הצג רק"** - תפריט פילטר
  - **"נוכחים"** - הצגת נוכחים בלבד
  - **"חסרים"** - הצגת חסרים בלבד
  - **"מאחרים"** - הצגת מאחרים בלבד
  - **"הכל"** - הצגת כולם
- **"חיפוש..."** - placeholder של חיפוש

### ⚠️ הודעות מערכת
- **"חובה לבחור סדר!"** - שגיאת validation לאירוע
- **"חובה להכניס יום"** - שגיאת validation לתאריך
- **"לא נמצאו תלמידים"** - מצב ריק ברשימת תלמידים
- **"אין אירועים קודמים"** - מצב ריק ברשימת אירועים
- **"טוען אירועים..."** - מצב טעינה
- **"מעדכן..."** - הודעת טעינה בעידכון
- **"העדכון הצליח!"** - הודעת הצלחה
- **"העידכון נכשל!"** - הודעת שגיאה
- **"הנתונים הועתקו בהצלחה"** - הודעת העתקה
- **"הנתונים הודבקו בהצלחה"** - הודעת הדבקה

## סלקטורים לטסט

### 🎯 Data-testid קיימים
```javascript
// רשימת אירועים קיימים
await page.getByTestId('event-list')

// רשימת תלמידים
await page.getByTestId('student-list')

// כפתור עידכון
await page.getByTestId('update-button')
```

### 🎯 Data-testid שיתווספו
```javascript
// מסך בחירת אירוע
await page.getByTestId('add-event-button')      // כפתור הוסף אירוע
await page.getByTestId('hebrew-date-picker')    // בוחר תאריך עברי
await page.getByTestId('event-select')          // בוחר אירוע
await page.getByTestId('start-registration')    // כפתור התחל רישום
await page.getByTestId('existing-events-button') // כפתור אירועים קיימים

// כפתורי ניווט ופעולות
await page.getByTestId('back-button')           // כפתור חזור
await page.getByTestId('copy-button')           // כפתור העתק
await page.getByTestId('paste-button')          // כפתור הדבק
await page.getByTestId('delete-button')         // כפתור מחק

// תוויות סיכום
await page.getByTestId('present-count')         // מספר נוכחים
await page.getByTestId('absent-count')          // מספר חסרים
await page.getByTestId('total-count')           // סה"כ תלמידים
```

### 🎯 סלקטורי טקסט
```javascript
// כותרות ותוויות
await page.getByText('רישום אירוע')
await page.getByText('בחר אירוע לרישום')
await page.getByLabel('תאריך עברי')
await page.getByLabel('אירוע')

// כפתורים
await page.getByRole('button', { name: 'התחל רישום' })
await page.getByRole('button', { name: 'בחר אירוע קיים' })
await page.getByRole('button', { name: 'חזור' })

// הודעות מערכת
await page.getByText('טוען אירועים...')
await page.getByText('לא נמצאו תלמידים')
await page.getByText('העדכון הצליח!')
```

## תרחישי בדיקה קריטיים

### ✅ בדיקות חובה
1. **טעינת דף** - וידוא שהמסך נטען תקין
2. **validation טפסים** - בדיקת הודעות שגיאה
3. **זרימת יצירת אירוע** - מתחילה ועד סוף
4. **זרימת עריכת אירוע** - בחירה מרשימה קיימת
5. **פונקציונליות העתק/הדבק** - שמירה והחזרת נתונים
6. **מחיקת אירוע** - ווידוא שנמחק מהרשימה
7. **בדיקת מצבים ריקים** - אין תלמידים/אירועים

### ⚡ בדיקות משנה
1. **פילטרים וחיפוש** - תפונקציונליות הסינון
2. **עדכון נוכחות** - שינוי סטטוס תלמידים
3. **הודעות מערכת** - toast notifications
4. **ניווט** - מעבר בין מסכים
5. **responsive** - התנהגות במכשירים שונים

## הערות טכניות

### ⏱️ Timeouts מומלצים
- **טעינת דף**: 60 שניות
- **טעינת נתונים**: 10 שניות
- **פעולות רגילות**: 5 שניות
- **אנימציות**: 2 שניות

### 🔄 פעולות מקבילות
ניתן להריץ במקביל:
- בדיקות validation שונות
- טסטי פילטרים שונים
- בדיקות הודעות מערכת

### 🚨 נקודות שבירה אפשריות
1. **טעינת רשימת תלמידים** - עלולה להימשך זמן רב
2. **שמירת נתונים** - תלוי בחיבור לשרת
3. **העתק/הדבק** - תלוי ב-localStorage
4. **תאריכים עבריים** - המרות מורכבות
