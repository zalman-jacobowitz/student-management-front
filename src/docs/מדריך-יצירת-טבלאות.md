# מדריך יצירת טבלאות במערכת

## סקירת הארכיטקטורה

המערכת משתמשת בגישה מבוססת-קונפיגורציה עם הקומפוננטה `FullTableWrapper` שמטפלת ביצירת טבלאות דינמיות. הנה המדריך המלא:

## 1. קונפיגורציה בסיסית של טבלה

### 1.1 יבוא התלויות הנדרשות
```javascript
import { FullTableWrapper } from "src/components/full-table/view";
import { TableConfig } from "src/components/full-table/types";
```

### 1.2 יצירת אובייקט קונפיגורציה לטבלה
הקונפיגורציה הראשית עוקבת אחר הממשק `TableConfig`:

```javascript
const tableConfig: TableConfig = {
  heading: {
    links: BREADCRUMB_LINKS,           // קישורי ניווט
    title: 'כותרת_הטבלה_בעברית',      // כותרת הטבלה
    importButton: true/false,          // כפתור יבוא
  },
  toolbar: {
    listActionsMap: ACTION_BUTTONS_ARRAY,  // מערך כפתורי פעולות
    removeAction: true/false,              // פעולת מחיקה
    onDelete: (selected) => handleDelete(selected)  // פונקציית מחיקה
  },
  data: {
    tableData: YOUR_DATA_ARRAY,       // מערך הנתונים
    tableColumns: COLUMN_DEFINITIONS, // הגדרות עמודות
  },
  rowDetails: {
    specialRow: ['checkbox', 'avatar', 'edit'],  // סוגי עמודות מיוחדות
    id: 'unique_id_field',                      // שדה מזהה ייחודי
    EditComponent: YourEditComponent,           // קומפוננטת עריכה
  },
  tableDetails: {
    styleTable: 'default',    // סגנון טבלה
    pagination: true/false,   // חלוקה לעמודים
    addButton: true/false,    // כפתור הוספה
    defaultValues: DEFAULT_ROW_VALUES  // ערכי ברירת מחדל
  }
}
```

## 2. מבנה הגדרת עמודות

### 2.1 מאפיינים בסיסיים של עמודה
כל עמודה צריכה להכיל את המאפיינים הבאים:
```javascript
{
  client: "kg_gdola",                    // לקוח
  filters: "regular" | "extra" | "",    // סוג סינון
  group_name: "primary" | "secondary" | "", // קבוצת עמודה
  hidden: "" | "1.0",                   // מוסתר/גלוי
  label: "שם התצוגה בעברית",           // תווית העמודה
  name: "field_name",                    // שם השדה
  required: "true" | "false" | "",      // חובה/לא חובה
  sorting: "1.0",                       // סדר מיון
  table_name: "your_table_name",        // שם הטבלה
  type: "text" | "number" | "select" | "date" | "checkbox", // סוג העמודה
  user_id: "user_email",                // מזהה משתמש
  width: 120 // רוחב (אופציונלי)
}
```

### 2.2 סוגי עמודות עם אפשרויות
עבור עמודות בחירה, יש להוסיף אפשרויות:
```javascript
{
  // ...מאפיינים בסיסיים
  type: "select",
  options: [
    { value: 'option1', label: 'תווית עברית', icon: 'solar:icon-name' },
    { value: 'option2', label: 'תווית עברית', icon: 'solar:icon-name' }
  ]
}
```

## 3. ניהול מידע

### 3.1 שליפת מידע
שימוש ב-React Query עם Suspense:
```javascript
const infoData = useSuspenseQuery(apiFunction());
const infoColumns = useInfoColumns('table_name');
```

### 3.2 מוטציות מידע
```javascript
const queryClient = useQueryClient();
const mutate = useMutation(updateFunction({queryClient}));
```

## 4. דוגמת יישום מלאה

### 4.1 קומפוננטת תצוגה ראשית
```javascript
function YourTableMainView() {
  const infoColumns = useInfoColumns('your_table_name');
  const infoData = useSuspenseQuery(apiYourData());
  const router = useRouter();
  
  const config: TableConfig = {
    heading: {
      links: YOUR_BREADCRUMB_LINKS,
      title: 'הכותרת שלך בעברית',
      importButton: true,
    },
    data: {
      tableData: infoData.data,
      tableColumns: infoColumns.newData,
    },
    rowDetails: {
      specialRow: ['checkbox', 'avatar', 'edit'],
      id: 'your_unique_id',
      EditComponent: YourEditDialog,
    },
    tableDetails: {
      styleTable: 'default',
      pagination: true,
      addButton: true,
    }
  };

  return <FullTableWrapper config={config} />;
}
```

### 4.2 עטיפה עם Suspense
```javascript
export function YourTableWrapper() {
  return (
    <Suspense fallback={<LoadingScreen />}>
      <YourTableMainView />
    </Suspense>
  );
}
```

## 5. פיצ'רים מיוחדים

### 5.1 קומפוננטת עריכה מותאמת
יצירת דיאלוג שמקבל props של `{ open, onClose, column }`

### 5.2 פעולות בסרגל כלים
```javascript
const listActionsMap = [
  {
    icon: 'solar:settings-bold',
    label: 'תווית עברית',
    onClick: () => handleAction()
  }
];
```

### 5.3 פונקציונליות מחיקה
```javascript
const submitDelete = useCallback(async (selectedIds) => {
  const promise = mutate.mutateAsync({
    data: selectedIds.map(id => ({your_id_field: id})), 
    mode: 'delete'
  });
  
  toast.promise(promise, {
    loading: 'מחיקה...',
    success: 'המחיקה הצליחה!',
    error: 'המחיקה נכשלה!',
  });
}, []);
```

## 9. טיפים חשובים

### 9.1 עקביות בעברית
- כל הטקסטים הפונים למשתמש צריכים להיות בעברית
- שימוש בדפוסי סגנון תואמי RTL
- טיפול נכון בתאריכים עבריים

### 9.2 ניהול מידע
- נתוני התלמידים הם הישות הראשית
- קונפיגורציה דינמית של עמודות מאפשרת תצוגות מותאמות
- תמיכה בפעולות קבוצתיות ליעילות
- יבוא/יצוא אקסל להעברת נתונים

### 9.3 אימות והרשאות
- Supabase מטפל באימות משתמשים
- ניהול אוטומטי של אסימוני JWT
- שמירת מצב אימות בין בדיקות
- הרשאות משתמשים שולטות בגישה לפיצ'רים

## 10. בדיקות
